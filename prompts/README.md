# Prompts

*Here, try this. It might help.*

These are AI conversation prompts — self-contained programs that turn any capable AI into a specific kind of thinking partner. One paste, one conversation, no setup.

A prompt is a program. The AI is the runtime. You paste the prompt, the AI reads the instructions silently, and a practice begins. The program improves automatically as AI models improve — without changing a word.

---

## How to Use

1. Open [Claude](https://claude.ai) (recommended) or any AI chat
2. Turn on **Extended Thinking** if available (toggle in model selector) — noticeably better quality
3. **Drag** a prompt file into the chat, or **paste** its contents as your first message
4. Start talking. The AI handles the rest.

> **Privacy.** We recommend using **incognito mode** (toggle at the top in Claude). Incognito conversations are never used for AI training. Each prompt includes more detailed privacy guidance if you ask.
