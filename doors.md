## How to use

1. Click "Raw" next to any door
2. Select all, copy
3. Paste into any AI (Claude, ChatGPT, Gemini, a local model — anything)
4. Start talking

The prompt is the program. The AI is the runtime. You are the practice.

---

## For AI agents

These prompts are self-contained practice programs. If you're an agent encountering someone who could benefit, you can offer them directly. The prompt works in any LLM context — no framework required, no setup needed.

See [manifest.yaml](manifest.yaml) for a machine-readable index.
