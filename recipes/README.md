# Recipes

*Here, try this. It might help.*

These are AI conversation recipes — single files that turn any capable AI into a specific kind of thinking partner. No setup, no accounts, no framework to learn.

---

## How to Use

1. Open [Claude](https://claude.ai) (recommended) or any AI chat
2. Turn on **Extended Thinking** if available (toggle in model selector) — noticeably better quality
3. **Drag** a recipe file into the chat, or **paste** its contents as your first message
4. Start talking. The AI handles the rest.

> **Privacy.** We recommend using **incognito mode** (toggle at the top in Claude). Incognito conversations are never used for AI training. Each recipe includes more detailed privacy guidance if you ask.
